# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use semantic versioning.

## [0.1.0] - 2026-08-30

### Added

- Offline `plan` and `audit` commands with stable text and JSON reports.
- Carrier-spacing plus two- and three-transmitter third-order conflict witnesses.
- Integer-kHz candidate generation, declared exclusions, and thresholded scan CSV evidence.
- Deterministic bounded search with distinct found, infeasible, and exhausted results.
- Cross-platform tests, reproducible examples, packaging audits, and clean-wheel smoke tests.
